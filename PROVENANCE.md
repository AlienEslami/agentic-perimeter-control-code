# Provenance and packaging

The imported code and records come from `AlienEslami/agentic-perimeter-runtime-certification`, commit `9b64daba8cbeaf08922bdbd45886093bd248c6e6`. `SOURCE_MANIFEST.json` records the original SHA-256 value of every imported file. This new repository is a curated distribution, not the complete development history. The original repository is preserved.

Packaging changes comprise the root documentation, dependency list, compressed record bundle, safe extraction script, offline smoke check, and a result-audit entry point that no longer requires an old manuscript PDF or source. Plotting entry points are supplied for the figures backed by numerical records. Scientific source snapshots and certificate-bound model files are retained without changes.

Excluded material consists of manuscript PDFs and LaTeX sources, document-editing and release-preparation scripts, unused illustrative figures, earlier manuscript archives, superseded preliminary experiment runs, unused exploratory drivers, and redundant tabular exports recoverable from the retained per-case records. Failed checks from the reported experiments remain in the data.

Directory and method names inside historical numerical records are preserved to keep the code and evidence consistent. The manuscript's terminology is explained in the reproduction guide. Experimental agent records are research data and are retained.

Existing authorship and literature attributions in source files remain in place. No new software license is imposed by this packaging operation.
